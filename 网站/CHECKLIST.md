## 🔍 常见问题与解决

### 问题：Pages 在 Gitee 网页没有启用
**解决**: 手动在 Gitee 网页开启 Pages 服务

### 问题：白屏或 404
**原因**: Vite base 配置错误
**解决**: 
```bash
# 检查 .env.production
VITE_BASE=/personal-website/  # 确认与仓库名匹配

# 或者访问：
https://gitee.com/wang12890391289321/personal-website
```

### 问题：刷新页面 404
**解决**: 确认 `dist/404.html` 存在 (已修复)
