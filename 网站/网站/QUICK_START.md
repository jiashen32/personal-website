# 🚀 快速部署指南

> 只需 3 步，5 分钟完成部署！

## ⚡ 第一步：访问 Gitee 仓库 (1 分钟)

打开浏览器访问：
```
https://gitee.com/wang12890391289321/personal-website
```

## ⚡ 第二步：启用 Pages (2 分钟)

1. 在左侧菜单点击 **"Pages"** 或 **"代码仓库" → **"Gitee Pages"**
2. 点击 **"启用 Pages"**
3. 勾选 `master` 分支 和 `root` 目录
4. 点击 **"保存"**

## ⚡ 第三步：等待并访问 (2 分钟)

1. 等待页面自动部署
2. 访问你的网站：
   ```
   https://gitee.com/wang12890391289321/personal-website
   ```
